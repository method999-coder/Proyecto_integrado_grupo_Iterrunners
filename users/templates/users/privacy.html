Política de Privacidad

Iter Runners es una aplicación para corredores y profesores que permite visualizar planes de entrenamiento, registrar cumplimiento y sincronizar actividades personales desde Strava. El tratamiento de datos se realiza únicamente para entregar funciones deportivas dentro de la aplicación y bajo control del usuario.

Datos que tratamos

Con consentimiento explícito, Iter Runners puede tratar datos de cuenta y actividad provenientes de Strava, incluyendo identificador de atleta, tokens de acceso/renovación y métricas deportivas como distancia, tiempo, ritmo, elevación, fecha y tipo de actividad. También puede tratar información básica de perfil del usuario dentro de la aplicación (nombre, grupo y registros de cumplimiento).

Finalidad del tratamiento

Estos datos se utilizan para mostrar estadísticas personales, historial de actividad, seguimiento de entrenamientos y funcionalidades internas del club. Si el usuario lo decide, una actividad puede publicarse en el feed interno y ciertos registros pueden publicarse en rankings deportivos (por ejemplo, controles de 3000m y distancias de carrera habilitadas). Cuando el usuario sincroniza Strava, esos datos se usan para alimentar vistas deportivas dentro de la app. Iter Runners no utiliza estos datos para vender perfiles ni para fines publicitarios ajenos al servicio.

Medidas de seguridad

Aplicamos medidas técnicas y organizativas razonables para proteger la información, incluyendo uso de HTTPS en producción, controles de sesión, protección CSRF, manejo de secretos mediante variables de entorno y reducción de exposición de datos sensibles en logs. El acceso a funciones de datos personales requiere autenticación.

Retención y eliminación

Los datos se conservan mientras sean necesarios para las funcionalidades activas de la cuenta. El usuario puede desconectar Strava y eliminar los datos sincronizados en la aplicación desde la opción "Eliminar datos de Strava" en el menú de usuario. Esta acción elimina los datos locales asociados y revoca la conexión, pudiendo volver a sincronizarse si el usuario reconecta Strava posteriormente.

Control y derechos del usuario

El usuario puede conectarse o desconectarse de Strava en cualquier momento, decidir si publica actividades en el feed interno y solicitar actualización o eliminación de sus datos dentro de la aplicación. Para dudas sobre esta política, puede contactar al administrador del servicio.
